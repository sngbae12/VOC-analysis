# 고객사 VOC 분석 웹앱

업로드한 VOC CSV로 항목별 비율, 불만 키워드 그림, 한글 워드 보고서를 만드는 Gradio 웹앱입니다.

GitHub 저장소는 **소스 배포용**입니다. 앱은 내려받은 Windows 컴퓨터에서 실행합니다. 클라우드에서 분석이 돌아가거나, GitHub이 고객 데이터를 받아 처리하지는 않습니다.

이 저장소의 샘플은 가상으로 만든 연습 데이터입니다. 실제 고객 데이터는 포함되어 있지 않습니다.

## 구현된 기능

- CSV 업로드 또는 실습 샘플 적용. 새 데이터는 기존 데이터를 **교체**하며 행을 누적하지 않습니다.
- 산업군·제품명·분야별 VOC 건수와 비율(%) 표, 화면용 Plotly 막대그래프
- 불만 열 기준 키워드 워드클라우드
- 통계·그림·이슈 요약을 담은 `.docx` 보고서
- 업로드 실패 후에도 이전 데이터를 유지하고, 다른 파일이나 같은 파일을 다시 적용할 수 있음

구현하지 않은 기능(로그인, 다중 사용자 저장소, GPU 추론, 자동 분류 모델 학습)은 제공하지 않습니다.

## 기술 스택과 분석 흐름

| 구성 | 실제 사용 |
|---|---|
| 화면 | Gradio 6 Blocks |
| 표·통계 | pandas |
| 화면 막대그래프 | Plotly (브라우저에서 그림) |
| 보고서용 PNG | matplotlib (Chrome 불필요) |
| 워드클라우드 | wordcloud, matplotlib |
| 보고서 | python-docx |
| 이슈 문장만 | CrewAI + OpenAI `gpt-4o-mini`(기본) |

1. **데이터 불러오기**: CSV를 읽고 필수 열을 확인한 뒤 메모리에 **교체** 저장합니다.
2. **통계분석**: pandas로 비율을 계산하고 Plotly 그래프를 화면에 표시합니다. 보고서용 PNG는 matplotlib로 저장합니다. OpenAI는 호출하지 않습니다.
3. **워드클라우드**: 불만 문구를 이 컴퓨터에서 토큰화해 그림을 만듭니다. OpenAI는 호출하지 않습니다.
4. **보고서생성**: 통계·워드클라우드·DOCX는 이 컴퓨터에서 만듭니다. API 키가 있을 때만 이슈 문장을 OpenAI에 요청하고, 그 **이번 작업** 내용으로 DOCX를 다시 저장합니다.

GPU는 쓰지 않습니다. Chrome이 없어도 통계·워드클라우드·보고서는 동작합니다. (Plotly PNG를 Kaleido/Chrome으로 저장하는 경로는 사용하지 않습니다.)

### 외부로 전송되는 내용

OpenAI를 호출할 때 **CSV 파일 전체는 업로드하지 않습니다.** `build_voc_digest()`가 만든 요약만 이슈 생성 프롬프트에 들어갑니다.

- VOC 총건수, 기간, 산업군·제품·분야 고유 값 수
- 산업군·분야·제품명별 건수와 비율
- 산업군별 **대표 불만 문구**(산업군 최대 8개, 각 4건)
- 불만 키워드 상위 25개

`고객명`, `지역`, `순번` 열은 요약에 넣지 않습니다. 다만 **불만 문구 안에 이름·연락처 등 개인정보가 있으면 그대로 전송될 수 있습니다.**

인터넷이 필요한 단계: 이슈 문장용 OpenAI 호출뿐입니다.

## 폴더 구조

```
VOC-analysis/
  voc_analysis_app.py   앱 본체
  sample_voc.csv        가상 실습 샘플 (50건)
  requirements.txt      직접 import하는 패키지 (UTF-8)
  start.bat             Windows 실행
  .env.example          환경 변수 예시 (키 값은 비움)
  README.md
  output/uploads/       업로드 복사본 (Git·파일 다운로드 대상 아님)
  output/exports/       화면/다운로드용 PNG·DOCX
```

`output/`은 없으면 앱이 만듭니다.

## GitHub에서 내려받기

```powershell
git clone https://github.com/sngbae12/VOC-analysis.git
cd VOC-analysis
```

ZIP으로 받은 경우 압축을 풀고 그 폴더에서 아래 설치를 진행합니다.

## 실행 환경과 설치

- Windows 10/11
- **Python 3.11 이상** (작성 환경: Python 3.11.9). pandas 3.0·matplotlib 3.11이 3.11을 필요로 합니다.
- 한글 폰트: 기본적으로 Windows `Fonts`의 맑은 고딕. 앱이 파일을 등록한 뒤 실제 폰트 이름을 사용합니다.
- 사용자 지정 폰트: 환경 변수 `VOC_FONT_PATH`에 `.ttf`/`.ttc` 경로를 지정합니다. 파일명 대신 등록된 폰트 패밀리명으로 그립니다.

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -U pip
python -m pip install -r requirements.txt
```

`requirements.txt`에는 이 앱이 직접 사용하는 패키지와, 작성 시 확인한 버전만 적었습니다. 개발 PC의 전체 pip 목록은 넣지 않았습니다.

## 모델·API 준비

로컬 LLM 파일이나 Hugging Face 모델은 **필요하지 않습니다.**

이슈 문장(보고서 4~5장)을 만들려면 OpenAI API 키가 필요합니다.

1. 앱 상단 **OpenAI API 키** 칸에 본인 키를 입력합니다. 기본값은 비어 있습니다.
2. 비우면 환경 변수 `OPENAI_API_KEY`를 사용합니다. 사용자가 직접 만든 `.env`가 있으면 프로젝트 폴더 기준으로 읽습니다.
3. 앱은 키를 파일, 로그, Git, URL, 브라우저 저장소에 쓰지 않습니다. 화면에서 입력한 키는 해당 보고서 작업이 끝나면 입력란에서 지우고, 요청용 객체도 버리지 않고 붙잡아 두지 않습니다.
4. **사용자가 만든 `.env`나 환경 변수 파일은 앱이 수정하지 않습니다.**
5. 모델 이름은 기본 `gpt-4o-mini`이며, `OPENAI_MODEL_NAME`으로 바꿀 수 있습니다.

키가 없거나 이슈 생성이 실패해도 통계·워드클라우드와 이번 작업의 워드 파일은 이 컴퓨터에서 만들 수 있습니다. 그 경우 미리보기와 DOCX에는 이슈 실패 안내가 들어가며, 이전 이슈를 성공 결과처럼 보여 주지 않습니다.

## 실행과 접속

`start.bat`을 더블클릭하거나:

```powershell
python voc_analysis_app.py
```

`.venv`가 있으면 `start.bat`이 프로젝트 폴더의 그 Python을 먼저 사용합니다.

접속 주소: [http://127.0.0.1:7860](http://127.0.0.1:7860)

## 지원 파일 형식과 스키마

지원 형식: **`.csv`만**. 인코딩은 UTF-8(BOM 포함), UTF-8, CP949, EUC-KR 순으로 시도합니다.

필수 열:

| 열 | 형식 | 설명 |
|---|---|---|
| 순번 | 값 있음 | 식별용 |
| 일자 | 날짜로 해석 | 잘못된 값은 기간 계산에서 빠짐 |
| 고객명 | 문자열 | 화면 미리보기용. OpenAI 요약에는 넣지 않음 |
| 산업군 | 문자열 | 통계 기준 |
| 지역 | 문자열 | 화면 표시 |
| 제품명 | 문자열 | 통계 기준 |
| 분야 | 문자열 | 통계 기준 |
| 불만 | 문자열 | 내용이 있는 행만 분석. 이슈 요약에 대표 문구로 들어갈 수 있음 |

선택 열은 있어도 되고, 앱이 필수로 쓰지는 않습니다. `불만`이 비어 있는 행은 제외합니다.

xlsx, 빈 파일, 필수 열 누락, 깨진 CSV는 화면에서 이유를 보여 주고, 이미 적용된 데이터가 있으면 그 데이터를 유지합니다.

## 가상 샘플 사용

`sample_voc.csv`는 한빛제조, 동서정밀 등 **가상의 회사·불만** 50건입니다. 앱에서 **실습 샘플 불러오기**를 누르면 이 파일을 적용합니다.

샘플로 확인한 것은 화면이 열리는지, 업로드·통계·워드클라우드가 동작하는지입니다. 분류 정확도나 업무 성과를 보장하지 않습니다.

## 데이터 보관 위치와 다운로드 범위

| 위치 | 내용 | 브라우저 파일 제공 |
|---|---|---|
| 메모리 `STORE` | 현재 적용된 표와 분석 결과. 새 파일/샘플로 **교체** | 해당 없음 |
| `output/uploads/` | 업로드 원본 복사, 현재 적용 CSV | 제공하지 않음 |
| `output/exports/` | 보고서용 PNG, 워드클라우드 PNG, `.docx` | 화면에 표시·다운로드 |
| 프로젝트 루트 `.env`, `.git`, `.venv` | 설정·코드 | 제공하지 않음 |

Git에는 `output/`과 `.env`를 올리지 않습니다. 실제 고객 CSV를 이 폴더에 두어도 커밋 대상이 아닙니다.

## 확인한 테스트와 미검증 항목

- 별도 `.verify_venv`: `pip install -r requirements.txt` 후 `pip check`(깨진 의존성 없음), 앱 모듈 import
- 로컬 함수: 샘플 50건, Chrome/`write_image` 없이 통계 표·Plotly 그래프, PNG 실패 시에도 표/그래프 유지, 환경 변수가 있어도 통계·워드클라우드에서 LLM 미생성, HTML 태그가 있는 산업군·파일명의 이스케이프, 이슈 대역 성공 시 미리보기와 DOCX 동일, 시간 초과 시 이전 이슈를 쓰지 않고 실패 안내 포함 보고서 저장, 키 없이 DOCX 생성, 업로드는 `uploads/`·결과는 `exports/`
- Gradio API: 샘플·통계·워드클라우드·키 없는 보고서, 다른 파일 연속 적용, 같은 파일 재적용, 잘못된 파일 후 기존 유지·재시도, 가짜 `.env`/`.git`/소스 CSV는 HTTP 403, export DOCX는 200
- 브라우저: 실습 샘플 적용, `선택됨 · 실습 샘플`, 50건 미리보기
- 미검증: 실제 OpenAI 유료 호출, 다른 Windows PC에서의 첫 설치 전체 화면 조작

## 현재 제한사항

- 한 번에 하나의 VOC 집합만 다룹니다. 여러 파일을 합치지 않습니다.
- 외부 공개 주소가 아니라 `127.0.0.1`에서만 엽니다.
- 한글 워드클라우드·보고서는 Windows 한글 폰트에 의존합니다.
- 이슈 문장 품질은 모델과 네트워크에 따라 달라집니다. 실패해도 로컬 통계 보고서는 저장됩니다.
- 그림 PNG 저장이 실패하면 표는 남고, 보고서는 그림 누락 안내와 함께 저장됩니다. 그 경우 완전한 보고서로 표시하지 않습니다.
- 업로드된 실제 고객 데이터는 `output/uploads/`에 남습니다. 공유 전에 직접 지우세요.
