# 고객사 VOC 분석 웹앱

업로드한 VOC CSV로 항목별 비율, 불만 키워드 그림, 한글 워드 보고서를 만드는 Gradio 웹앱입니다. 통계와 그림은 이 컴퓨터에서 계산하고, 이슈 문장은 OpenAI API가 있을 때 CrewAI 에이전트가 작성합니다.

이 저장소의 샘플은 가상으로 만든 연습 데이터입니다. 실제 고객 데이터는 포함되어 있지 않습니다.

## 구현된 기능

- CSV 업로드 또는 실습 샘플 적용. 새 데이터를 적용하면 이전 통계·워드클라우드·보고서를 비웁니다. 행을 누적하지 않습니다.
- 산업군·제품명·분야별 VOC 건수와 비율(%) 표, Plotly 막대그래프
- 불만 열 기준 키워드 워드클라우드
- 산업군·분야 통계, 워드클라우드, 이슈 요약을 담은 `.docx` 보고서
- 업로드 실패 후에도 이전 데이터를 유지하고, 다른 파일이나 같은 파일을 다시 적용할 수 있음

구현하지 않은 기능(로그인, 다중 사용자 저장소, GPU 추론, 자동 분류 모델 학습)은 제공하지 않습니다.

## 기술 스택과 분석 흐름

| 구성 | 실제 사용 |
|---|---|
| 화면 | Gradio 6 Blocks |
| 표·통계 | pandas |
| 막대그래프 | Plotly, PNG 저장에 Kaleido |
| 워드클라우드 | wordcloud, matplotlib |
| 보고서 | python-docx |
| 에이전트 | CrewAI + OpenAI `gpt-4o-mini`(기본) |

1. **데이터 불러오기**: CSV를 읽고 필수 열을 확인한 뒤 메모리(`STORE`)에 **교체** 저장합니다.
2. **통계분석**: CrewAI VOC Agent가 도구를 호출하려고 시도합니다. API 키가 없거나 Crew가 실패하면 pandas/Plotly로 같은 그래프를 만듭니다. GPU는 쓰지 않습니다.
3. **워드클라우드**: 불만 문구를 이 컴퓨터에서 토큰화합니다. Crew 실패 시에도 동일 함수로 그림을 만듭니다.
4. **보고서생성**: 로컬에서 통계·워드클라우드를 준비한 뒤, API가 있으면 요약 텍스트를 OpenAI에 보내 이슈 문장을 받습니다. 워드 파일 자체는 이 컴퓨터에서 저장합니다.

### 외부로 전송되는 내용

OpenAI를 호출할 때 **CSV 파일 전체는 업로드하지 않습니다.** `build_voc_digest()`가 만든 요약만 프롬프트에 들어갑니다.

- VOC 총건수, 기간, 산업군·제품·분야 고유 값 수
- 산업군·분야·제품명별 건수와 비율
- 산업군별 대표 불만 문구(산업군 최대 8개, 각 4건)
- 불만 키워드 상위 25개

`고객명`, `지역`, `순번` 열은 요약에 넣지 않습니다. 다만 불만 문구 안에 고유명사가 있으면 그대로 전송될 수 있습니다.

인터넷이 필요한 단계: OpenAI 에이전트 호출. 통계 그래프와 워드클라우드만 쓸 때는 키가 없어도 됩니다.

## 폴더 구조

```
VOC-analysis/
  voc_analysis_app.py   앱 본체
  sample_voc.csv        가상 실습 샘플 (50건)
  requirements.txt      직접 import하는 패키지
  start.bat             Windows 실행
  .env.example          환경 변수 예시 (키 값은 비움)
  README.md
  output/               실행 중 생성 (Git에 올리지 않음)
```

`output/`은 없으면 앱이 만듭니다. 업로드 복사본, 그래프 PNG, 워드 보고서가 여기에 쌓입니다.

## GitHub에서 내려받기

```powershell
git clone https://github.com/sngbae12/VOC-analysis.git
cd VOC-analysis
```

ZIP으로 받은 경우 압축을 풀고 그 폴더에서 아래 설치를 진행합니다.

## 실행 환경과 설치

- Windows 10/11
- Python 3.10 이상 (작성 환경: Python 3.11.9)
- 한글 폰트: 기본적으로 Windows `Fonts`의 맑은 고딕. 없으면 환경 변수 `VOC_FONT_PATH`에 `.ttf` 경로를 지정합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
```

`requirements.txt`에는 이 앱이 직접 사용하는 패키지와, 작성 시 확인한 버전만 적었습니다. 개발 PC의 전체 pip 목록은 넣지 않았습니다.

## 모델·API 준비

로컬 LLM 파일이나 Hugging Face 모델은 **필요하지 않습니다.**

이슈 문장(보고서 4~5장)을 만들려면 OpenAI API 키가 필요합니다.

1. 앱 상단 **OpenAI API 키** 칸에 본인 키를 입력합니다. 기본값은 비어 있습니다.
2. 비우면 환경 변수 `OPENAI_API_KEY`를 사용합니다. 사용자가 만든 `.env`가 있으면 프로젝트 폴더 기준으로 읽습니다.
3. 앱은 키를 파일, 로그, Git, URL, 브라우저 저장소에 쓰지 않습니다. 작업이 끝나면 메모리에서도 지웁니다.
4. 모델 이름은 기본 `gpt-4o-mini`이며, `OPENAI_MODEL_NAME`으로 바꿀 수 있습니다.

키가 없거나 호출이 실패해도 통계·워드클라우드와 수치 중심 워드 파일은 이 컴퓨터에서 만들 수 있습니다. 그 경우 이슈 문장은 생성되지 않습니다.

## 실행과 접속

`start.bat`을 더블클릭하거나:

```powershell
python voc_analysis_app.py
```

`.venv`가 있으면 `start.bat`이 그 Python을 먼저 사용합니다.

접속 주소: [http://127.0.0.1:7860](http://127.0.0.1:7860)

## 지원 파일 형식과 스키마

지원 형식: **`.csv`만**. 인코딩은 UTF-8(BOM 포함), UTF-8, CP949, EUC-KR 순으로 시도합니다.

필수 열:

| 열 | 형식 | 설명 |
|---|---|---|
| 순번 | 값 있음 | 식별용 |
| 일자 | 날짜로 해석 | 잘못된 값은 기간 계산에서 빠짐 |
| 고객명 | 문자열 | 화면 미리보기용. OpenAI 요약에는 넣지 않음 |
| 산업군 | 문자열 | 통계 기준 |
| 지역 | 문자열 | 화면 표시 |
| 제품명 | 문자열 | 통계 기준 |
| 분야 | 문자열 | 통계 기준 |
| 불만 | 문자열 | 내용이 있는 행만 분석 |

선택 열은 있어도 되고, 앱이 필수로 쓰지는 않습니다. `불만`이 비어 있는 행은 제외합니다.

xlsx, 빈 파일, 필수 열 누락, 깨진 CSV는 화면에서 이유를 보여 주고, 이미 적용된 데이터가 있으면 그 데이터를 유지합니다.

## 가상 샘플 사용

`sample_voc.csv`는 한빛제조, 동서정밀 등 **가상의 회사·불만** 50건입니다. 앱에서 **실습 샘플 불러오기**를 누르면 이 파일을 적용합니다.

샘플로 확인한 것은 화면이 열리는지, 업로드·통계·워드클라우드가 동작하는지입니다. 분류 정확도나 업무 성과를 보장하지 않습니다.

## 데이터 보관 위치

| 위치 | 내용 |
|---|---|
| 메모리 `STORE` | 현재 적용된 표와 분석 결과. 새 파일/샘플로 **교체** |
| `output/uploaded_voc.csv` | 현재 적용분 복사 |
| `output/upload_시각_원래이름.csv` | 업로드 원본 복사 |
| `output/voc_ratio_*.png`, `voc_wordcloud_*.png`, `VOC분석보고서_*.docx` | 생성 파일 |

Git에는 `output/`과 `.env`를 올리지 않습니다. 실제 고객 CSV를 이 폴더에 두어도 커밋 대상이 아닙니다.

## 확인한 테스트와 미검증 항목

- 코드 검토: 새 파일은 기존 데이터를 교체함, 적용 후 파일 칸을 비워 같은 파일을 다시 고를 수 있음, 샘플 선택 표시는 적용된 데이터와 맞춤, 분석 화면 제목·카드·표/그림 배치
- 로컬 함수: 가상 샘플 50건 로드, 빈 파일·필수 열 누락·CSV가 아닌 파일 오류 문구, 데이터 교체 시 이전 통계·그림·보고서 비움, API 키 없이 통계·워드클라우드·워드 파일 생성
- 브라우저: 실습 샘플 적용, 헤더에 현재 데이터·50건·선택됨 버튼, API 키 입력란(기본 빈 값)
- Gradio API(로컬 서버): 샘플 → 통계 표/그래프 → 워드클라우드 이미지 → 키 없이 보고서 파일, 다른 CSV 연속 적용, 같은 파일 재적용, 잘못된 파일 후 이전 데이터 유지·정상 파일 재시도
- OpenAI 실제 호출·잘못된 키 거부 메시지: 이 환경에 키가 없어 미검증
- 다른 Windows PC 신규 설치: 미검증 (작성 PC는 이미 패키지가 설치된 상태)

## 현재 제한사항

- 한 번에 하나의 VOC 집합만 다룹니다. 여러 파일을 합치지 않습니다.
- 외부 공개 주소가 아니라 `127.0.0.1`에서만 엽니다.
- 한글 워드클라우드·보고서는 Windows 한글 폰트에 의존합니다.
- CrewAI 에이전트 품질은 모델과 네트워크에 따라 달라지며, 실패 시 로컬 통계로 대체합니다.
- 업로드된 실제 고객 데이터는 `output/`에 남습니다. 공유 전에 직접 지우세요.
